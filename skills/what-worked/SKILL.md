# What worked

Reply in the user's language.

1. `list_sites`, pick the site.
2. `get_results`. Read `verdict` (trend, clicks vs previous period, difference), `score` (improved, stable, worse, measured) and `actions` (per change, with outcome).
3. Lead with the verdict in one sentence, with the real numbers.
4. List improved actions first, then worse ones. For worse ones, say it plainly: the measurement compares against the site's total trend, so a drop may not be caused by the edit; propose one concrete next check.
5. If `measured` is 0, say the 28-day window has not closed yet. Do not guess an outcome.
6. For a client report, keep it to: verdict, 3 best actions, 1 risk, next step.
